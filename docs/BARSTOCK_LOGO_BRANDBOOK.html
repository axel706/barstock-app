BarStock Pro

Logo Brandbook

A single, unambiguous specification for the BarStock Pro logo. Everything here is measured from the production application. If a value appears twice in this document, it is the same value — there are no alternates, no “approximately”, and no room for interpretation.

If you are an AI reproducing this logo: read section 03 (Canonical specification) and section 05 (Reproduction). Every measurement is expressed as a multiple of S, the font size of the wordmark. Do not infer values from the rendered images in this document — images compress, numbers do not. When you are done, verify against the checklist in section 10.

01 — The logo

BarStockPro

Primary — on dark backgrounds

BarStockPro

Primary — on light backgrounds

The logo is a wordmark with two fixed companions: a circular dot and the suffix PRO. The three elements are never separated, never reordered, and never rescaled independently of one another.

The single most common error. The word is BarStock — one word, two capitals, no space. Not “Bar Stock”, not “Barstock”, not “BARSTOCK”. The capital S in the middle is part of the mark.

02 — Anatomy

PartWhat it isNever
1 · WordmarkThe word BarStock set in Manrope ExtraBold with negative tracking.Never set in another weight, never letterspaced positively.
2 · DotA perfect circle in #38BDF8 resting on the baseline, immediately after the wordmark.Never a period, never vertically centred, never any other colour.
3 · SuffixPRO in uppercase, Bold, grey, with positive tracking, sharing the wordmark’s baseline.Never the same size or colour as the wordmark.

03 — Canonical specification

Every dimension is a multiple of S, the font size of the wordmark. Choose S, multiply, done. This is what makes the logo reproducible at any size in any medium.

The dot rests on the baseline. This is the rule most often broken. The dot is not centred on the x-height, not centred on the cap height, and not floating. Its lowest point touches the same invisible line the letters stand on — like a full stop, but round and blue.

04 — Colour

Dot blue#38BDF8 · rgb(56, 189, 248) · hsl(199, 93%, 60%)
Suffix grey#64748B · rgb(100, 116, 139) · hsl(215, 16%, 47%)
Wordmark on dark#F8FAFC · rgb(248, 250, 252)
Wordmark on light#0F172A · rgb(15, 23, 42)

The dot and the suffix keep their colour on every background. Only the wordmark changes, and only between the two values above — never to pure black, never to pure white.

Historical note. Earlier builds of the application rendered the dot as #3B82F6 in the app header while PDFs and emails used #38BDF8. That conflict is resolved: #38BDF8 is the only correct value. Any asset still showing #3B82F6 is out of date.

05 — Reproduction

Recommended · HTML and CSS

This is the most reliable method and the one to use whenever the medium allows it. The layout engine positions the dot and the suffix from the font’s own metrics, so nothing has to be measured and nothing can drift. Every value is expressed in em, which means the whole logo scales from a single font-size.

<span class="bs-logo" style="font-size:46px; color:#f8fafc">
  BarStock<span class="dot"></span><span class="pro">Pro</span>
</span>

<style>
.bs-logo{
  display:inline-flex;
  align-items:baseline;
  line-height:1;
  font-family:"Manrope",sans-serif;
  font-weight:800;
  letter-spacing:-.03em;
}
.bs-logo .dot{
  display:inline-flex;
  align-self:flex-end;
  width:.22em;  height:.22em;
  min-width:.22em; min-height:.22em;   /* stops flex from squashing it */
  border-radius:50%;
  background:#38bdf8;
  margin:0 .043em .13em .022em;        /* right, bottom, left */
}
.bs-logo .pro{
  font-size:.37em;
  font-weight:700;
  color:#64748b;
  letter-spacing:.08em;
  text-transform:uppercase;
  margin-left:.152em;
}
</style>

Why min-width and min-height are there. The dot is a flex child. Without the minimums a narrow container squashes it into an oval. This is not decoration — remove it and the logo eventually breaks.

SVG

Use SVG for a fixed asset — a favicon, an email header, a file someone will drop into a deck. One caveat decides how you generate it: the horizontal position of the dot and the suffix depends on the rendered width of the word BarStock, which only the font knows. Do not guess it.

Generate it from a real render instead. The button below measures the logo as it appears in this very document and writes the exact SVG for you.


  


  
If the wordmark will travel to systems where Manrope may be missing, convert the text to outlines after generating. Outlines are immune to font substitution, which is the other classic way this logo goes wrong.


  
PDF · jsPDF

  
Used by the application’s reports and purchase orders. Here S is the jsPDF font size.



const S = 22;                              // wordmark size
pdf.setFont('helvetica', 'bold');          // or an embedded Manrope
pdf.setFontSize(S);
pdf.setTextColor(248, 250, 252);           // #F8FAFC
pdf.text('BarStock', x, baseline);

const w = pdf.getTextWidth('BarStock');
const r = 0.11 * S;                        // radius = half of 0.22 S

pdf.setFillColor(56, 189, 248);            // #38BDF8
pdf.circle(x + w + 0.13 * S, baseline - r, r, 'F');   // bottom edge on the baseline

pdf.setFont('helvetica', 'bold');
pdf.setFontSize(0.37 * S);
pdf.setTextColor(100, 116, 139);           // #64748B
pdf.text('PRO', x + w + 0.43 * S, baseline);


  

    
jsPDF has no letter-spacing. The wordmark will render slightly wider than the CSS version and PRO slightly tighter. This is accepted and expected — do not attempt to compensate by inserting spaces between characters.

  


  
By hand · Figma, Illustrator, Canva

  
    
    
  1. Type BarStock in Manrope ExtraBold. Set tracking to −3%. Note the font size — this is S.
    2. 
    
  2. Draw a circle with a diameter of 22% of S. Hold shift so it stays a perfect circle.
    3. 
    
  3. Fill it with #38BDF8. No stroke, no shadow, no gradient.
    4. 
    
  4. Align the circle so its bottom edge touches the text baseline, and its left edge sits 2.2% of S after the final k.
    5. 
    
  5. Type PRO in Manrope Bold at 37% of S, tracking +8%, colour #64748B.
    6. 
    
  6. Put PRO on the same baseline, with its left edge 43% of S from the end of the wordmark.
    7. 
    
  7. Group the three. From here on they only ever scale together.
    8.

Manrope 800 is not the same as a browser’s synthetic bold. If only the regular weight loads, the browser will fake the weight and the wordmark will look thin and slightly smeared. When in doubt, compare against the images in section 01.


  
  
07 — Clear space and minimum size


  
Clear space: keep a margin of 0.5 S on all four sides, free of text, rules, edges and other logos. Measured from the outermost ink — the left edge of the B, the cap height of the B, the right edge of the O, and the descender line.


  
Minimum sizes:

  

    
MediumMinimum SWhy

    
Screen20 pxBelow this the dot is under 4.4 px and reads as an artefact.

    
Print7 mmBelow this the suffix tracking closes up and PRO becomes a blur.

    
Favicon—Do not shrink the full logo. Use the dot alone, or the letter B.

  


  
  
08 — Correct and incorrect


  

    
Correct
The dot rests on the baseline and is a perfect circle in #38BDF8.

    
Incorrect
The dot centred on the x-height, or floating between the letters and the suffix.

    
Correct
PRO in grey at 37% of the wordmark, with open tracking.

    
Incorrect
PRO matching the wordmark’s size or colour, which turns one logo into two words.

    
Correct
The whole lockup scaled from one value.

    
Incorrect
Resizing the wordmark and leaving the dot or the suffix behind.

    
Correct
Wordmark in #F8FAFC on dark, #0F172A on light.

    
Incorrect
Pure black, pure white, or tinting the wordmark with the dot blue.

  


  
Also never: rotate it, arch it, outline it, add a shadow or a glow, place it on a busy photograph without a solid or heavily blurred panel behind it, recolour the dot to match a campaign, or translate the word PRO.
